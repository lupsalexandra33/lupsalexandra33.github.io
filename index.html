Unikraft · Ruby support

2025 – present · C, Ruby, GNU build systems

Porting the Ruby interpreter to Unikraft and adding a Ruby application to the official catalog, working with the maintainers on review.

  • Ruby-Hello app with Firecracker supportcatalog-core #91
  • Update to Ruby 4.0.6 and port to musllib-ruby #4
  • Cannot unpack Ruby sourcelib-ruby issue #1
  • Add Rubycatalog-core issue #25

  1. Added a Ruby application to the catalog

    Wrote ruby-hello, a catalog application that runs on Firecracker, in 13 files and about 475 lines. It closes issue #25 and is currently in review.

  2. Found why the Ruby build had failed since 2021

    lib-ruby downloaded a GitHub branch archive that ships configure.ac but not the generated configure or the config.guess / config.sub helpers, so autoconf regenerated the script and the build stopped. I proposed using the official release tarball, which ships all three.

  3. Traced the remaining blockers

    Found that Ruby 2.6's OpenSSL extension fails on any distro with OpenSSL 3.0 because deprecation warnings are treated as errors. Also reported two gaps in the Unikraft core: a missing sys/prctl.h and undefined idtype_t / siginfo_t in the newlib layer.

  4. Porting to Ruby 4.0.6 on musl

    After discussing it with the maintainers, the port now targets Ruby 4.0.6 on musl. The update is open as lib-ruby #4.
